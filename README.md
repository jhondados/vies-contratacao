> Detecção de viés em processos seletivos com IA. Monitora decisões por gênero, idade e origem para promover diversidade e equidade.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/vies-contratacao/

## 📊 Resultados-chave (KPIs)
**monitorado** Viés · **+27%** Diversidade · **auditada** Equidade · **transparentes** Decisões

## 🧠 Tecnologias de IA
ML · Fairness · Bias Detection

## ✨ O que faz
- Auditoria de viés (gênero/idade)
- Métricas de fairness
- Funil de diversidade
- Recomendação de correção

## 🗄️ Fonte de dados real
[Processos seletivos](https://www.gov.br/trabalho)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com Processos seletivos
2. **Processamento com IA** — ML · Fairness · Bias Detection
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
